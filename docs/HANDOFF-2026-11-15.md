## 3. How it works

```text
Scratch image (Morphic)                     Python bridge (asyncio)
  chat pane / async worker   --8765-->   parse request + full context
  apply change set on UI thread <--     validate → repair → compile → literal
        │                                   │
        └── undo / registry                   └── model provider (openai-compatible)
```

- Every `#request` carries a **full snapshot**: sprites, stage variables/lists,
  costumes, sounds, and each script's id/label/hat/count/hash/ownership plus
  AI-owned bodies. The bridge validates against that snapshot, so undo and
  manual edits reconcile on the next turn; there is no separate sync message.
- The model emits a **JSON change set** of block IR. Python compiles it to
  native Scratch tuples; Squeak builds real `BlockMorph` stacks. No
  Python/Smalltalk is generated by the model.
- `owned=false` scripts are user-created and read-only; the model adds
  alongside them. Auto-apply with Undo; one change set per turn.
- Ports: **8765 = chat bridge**, **8767 = local dev control** (never expose
  8767; it compiles `.st` files).
- Protocol details: §11.2.

## 4. Model connection

Profiles live in `bridge/harness.ini` (start from `harness.ini.example`):
`opencode-go` (default), `deepseek-direct`, `local` (Ollama), `mock`.
Resolution: CLI > `DEEPSEEK_*` env > ini > built-in. The key lives only in
`bridge\.deepseek_key` or the environment.

```powershell
python -m harness.server --profile mock
python -m harness.server --profile opencode-go --timeout 60 --retries 1
python tools\ai_control.py bridge-status --json
```

| Layer | Budget |
|---|---|
| Squeak async worker | 300 s |
| Bridge turn | 240 s |
| Per model attempt | 120 s (opencode-go) |
| Output | 16 384 tokens (opencode-go) |
| Transport retries | 2 (backoff + `Retry-After`) |
| Repairs | 2, abandoned at the deadline |

Error codes: `auth`, `rate_limit`, `timeout`, `network`, `server`,
`bad_request`, `bad_json`, `cancelled`. The wire keeps the request id; detail
goes to `scratch\base\bridge.log` (redacted: no prompts, no key).

`bad_json` is **not** retried by the transport; the agent enters its repair
loop. Auth/bad-request/cancelled fail fast. Cancellation is cooperative:
`#(#cancel <id>)` stops the turn at the next attempt/repair and discards a late
reply; an HTTP call already in flight cannot be aborted. Deterministic
development: `--record`, `--replay`, `--cache`; `--prompt-budget <chars>`
(default 80 000; `run_live.ps1` uses 80 000). Trimming keeps script ids,
labels and ownership.

**Reasoning is off by default, explicitly.** The `opencode-go` profile sends
`thinking: {"type": "disabled"}`. Omitting it once let `deepseek-v4.1-flash`
spend the whole 8192-token completion on hidden reasoning and return empty
content (`finish_reason=length`), surfacing as invalid JSON. With reasoning
off, the calculator went from three 70–90 s failures to one 24.8 s success;
live pong took 13.8 s, a spinning bat 4.5 s. The gateway prompt-caches the
stable system prompt (~13 950/14 000 tokens), so hidden reasoning, not context
size, was the latency problem.

**Audit bundles.** `harness/audit.py` + `--audit off|meta|full`. `full` writes
per-turn prompts, context, every raw completion, validation issues, compiled
tuples/apply literal and `chunks/`. `meta` writes only `index.jsonl` and
`outcome.json`. Writes are best-effort; a failed audit never fails a turn.
Validation failures record their real attempt count (`ValidationError.attempts`).
These files contain prompts and model output: keep them local.

## 5. Progressive context

The always-on guide is `SCRATCH_AI_CONTEXT.md` (loaded by `context_doc.py`,
mtime-cached, sent with every system prompt). It carries Scratch semantics,
media rules, the large-task playbook and the context-pack index.

**Topic packs.** Optional detail lives in `context/`: `clones`, `games`,
`scrolling`, `pen-3d`. The model answers with:

```json
{ "load_context": ["clones"], "reason": "particle request" }
```

The agent appends the pack, rebuilds the prompt and asks again. Unknown or
duplicate names, mixing with `changes`, and more than two loads are repaired.
Loaded packs extend the budget by their own size, so they never steal room
from the core guide, media index or catalog.

**Sprite script detail.** The context lists each script's id, label, hat,
count and ownership; AI-owned bodies travel as an optional 8th script element.
When any exist, the system prompt adds an index:

```text
Sprite script detail available (return {"load_sprite": ["Name"], ...}):
  Bat: ai-1 chase, ai-4 reset
```

`{"load_sprite": ["Bat"]}` appends that sprite's exact blocks (24k cap per
sprite). Packs and sprites may be combined, never with `changes`; two loads per
turn; unknown names or sprites without editable scripts are repaired. Only
AI-owned bodies are sent; user scripts stay metadata-only.

**Contract:** request `load_sprite` only for an indexed sprite. If no index is
shown, exact bodies are unavailable in that turn; revise from ids, labels and
counts. The bridge's no-detail repair says the same and tells the model to
return a change set instead of retrying.

**Context downgrade hazard (session 20).** Reloading
`image/15_reply_context.st` after `25`/`28`/`35` used to overwrite the live
`scriptContextFor:`/`spriteContextFor:` with 7-element fallbacks, dropping
props, labels and bodies. The fallbacks are now guarded with
`includesSelector:`. If an image still shows a 7-element context, reload
`28` → `34` → `35` in that order, then run
`scratch/base/probes/probe_context_methods.st`; expect `spriteElements=8`,
`scriptElements=8`. See trap 60.

## 7. Failure modes

| Symptom | Cause | Fix |
|---|---|---|
| `ConnectionRefused` on 8767 | image not running / old image | `.\run_scratch.ps1`; check `ai_control.log` |
| `TimeoutError` on any command | modal dialog blocking the UI | screenshot, dismiss, retry `status` |
| "type your initials" popup | image renamed/moved, or Ctrl+V | type initials; next launch pins `ai` |
| `load` returns `error: syntax: …` | method compile failed | read the message, fix, `check_st.py`, reload |
| `ok send`, no block change | bridge `#error` or no-op | read reply / `ai_control.log`; `bridge-status` |
| `bridge-status` unreachable | bridge not running | start mock/live on 8765 |
| `run_live.ps1` port in use | older bridge alive | `-Reuse` or stop the PID |
| 401 from model | wrong key/endpoint | `bridge\.deepseek_key` + `opencode-go` |
| 429/5xx after retries | provider trouble | check `bridge.log`; retry later |
| `bad_json` / empty reply | malformed model output | automatic repair; `audit.py show latest --raw` |
| request cancelled | `#cancel` sent | expected; nothing applied |
| `load_sprite` rejected, `sprites with script detail: none` | 7-element context (trap 60) | reload `28 → 34 → 35` |
| text import loses a costume | PNG rejected by the 2009 reader | keep the `.bmp` copy |
| `bootstrap` → unknown command | `00_bootstrap.st` not loaded | load 00 first |
| Squeak opens a file picker | relative/absolute path with spaces | use `.\run_scratch.ps1` |

### 11.2 Wire protocol

TCP `127.0.0.1:8765`, 4-byte big-endian length, ASCII Smalltalk literal array.
Use `NetNameResolver addressForName: '127.0.0.1'` — never `localHostAddress`
on this machine.

```smalltalk
#(hello 'token' 'ScratchAI/1')      -> #(hello-ok 'ScratchAI/1')
#(ping)                             -> #(pong)
#(info)                             -> #(info 'ScratchAI/1' profile model base_url budget concurrent pending lastError)
#(cancel 123)                       -> #(ok 123) | #(error 123 'not running')
#(request 123 #('prompt') 'Sprite1' #(CONTEXT))
  -> #(result 123 #('summary...') #(#apply 123 #(...)))
  -> #(error 123 'message')
#(applied 123)                      -> #(ok 123)
```

Context: `#(target #(sprite...))`, sprite =
`#(name isStage vars lists costumes sounds scripts)` plus an optional 8th
element `#(x y direction size visible rotationStyle aiOwned costumeIndex)`.
Script = `#(id label hat blockCount hash owned userEdited)`, optionally
followed by the native tuple sequence for AI-owned scripts. Older 7-element
contexts still parse (but lose props, labels and lazy detail).

Apply: `#(#apply id #( #(#add 'ai-1' 'Sprite1' #(TUPLE...) 'label') ... ))`,
with `#replace`, `#delete`, `#createVariable`, `#createSprite`,
`#duplicateSprite`, `#deleteSprite`, `#addCostume`, `#setBackdrop`,
`#setSprite`. Backdrop/script targeting of `'Stage'` works.

### 11.8 Known limitations

- A modal dialog still wedges the dispatcher. Screenshot, dismiss, retry.
- A missing **relative** name passed to `ai_control.py load` can open a file
  picker; load `scratch/base/probes/*.st` by absolute path.
- Synchronous `send` blocks Squeak up to 300 s; prefer `send --async` or the
  rail's Send button (always async). Pending sends drop on project open/save.
- The native top bar spans the full window. The rail is a 358 x 683 visual body
  pane below it (352 px native reservation + 6 px overlap). The left side is
  native Scripts: 6 px left edge and rounded bottom-left corner. The right side
  and bottom edge are native library: 11 px outer right and 12 px bottom. The
  sprites/library bottom-right corner has a square outer edge while docked, so
  the outer edge runs straight into the bottom band; the native inner fillet
  remains between that straight edge and the sprites page background. Native
  panes still end at `x=968`; the rail starts at `x=962` and covers the outer
  6 px of the native library right edge. The page reserves 11 px right and 12 px
  bottom; the header is `#959A9F`, the page `#7C8083`. Collapse via the close
  button or File > AI Chat. The frame widens to
  1320 px on first dock.
- Bridge/Usage pages refresh on a background fork and scroll in short frames.
  The Bridge page's **Start** button launches the Python bridge from the image:
  it writes `scratch\base\bridge_start.cmd` (CRLF), opens it through
  `ScratchPlugin primOpenURL:`, and polls `#info` until the bridge answers. The
  script runs `run_live.ps1` when `bridge/.deepseek_key` exists, otherwise
  `run_bridge.ps1`; `bridgeLaunch=live|mock` in `harness.ini` overrides it.
  Stopping is still done by closing the launcher console or
  `tools\stop_bridge.ps1`. `#info` stays nine elements; `#options`/`#usage` are
  additive. Token totals reset when the bridge restarts; `Last turn` is a
  refresh delta. The Usage page switches the active model between DeepSeek and
  HY4 Flash Free through `#selectModel`; choices live in
  `bridge/config.py` (`MODEL_CHOICES`) and apply to the next turn. The switch is
  in-memory and resets with the bridge process.
- User scripts are read-only until a confirmation flow exists; lazy detail
  includes AI-owned bodies only.
- Load order matters: `09 → 28 → 34`; loading `09` after `28` erases sprite
  undo. `project open` resets registry/undo and restores ownership by hash.
- `.sb` is a binary `ObjStream`; use `project-export-text` for diffs. Text
  import uses `.bmp` copies because the 2009 PNG reader rejects some PNGs.
- `touching`/`distance_to`/`goto_sprite`/`point_towards` accept a sprite that
  already exists or was created earlier in the same change set.
- Custom blocks, sound import and `.sprite` bundles are not exposed. Clones are
  runtime-only and never appear in the context.
- WeDo/motor and obsolete 1.4 blocks are excluded. `math_function` exposes
  abs/sqrt/trig/ln/log/e^/10^.
- The context appendix adds ~9k prompt tokens and the curated media groups
  ~10k; a bare bridge below 80 000 chars trims them (media tail first).
- `--audit full` is local debugging, not a shareable log. Plan → per-script
  chunk generation is not implemented; `chunks/` records the one-shot
  decomposition.
- File > Save As is unusable in dev mode (trap 43); use `ai_control.py save`
  or `save-clean`.
- The mock context knows only `Sprite1`, `costume1`/`costume2`, `pop`.
- Scratch name/logo/cat and its media are trademarked/licensed; a public build
  must rename and replace them.
